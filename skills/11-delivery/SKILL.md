# Delivery Skill

## Objetivo

Encerrar o projeto somente após todos os gates.

## Checklist

- [ ] workflow completo ou etapas opcionais justificadas;
- [ ] Design Contract;
- [ ] Figma sync;
- [ ] copy status;
- [ ] code contract;
- [ ] implementation;
- [ ] QA;
- [ ] environment variables;
- [ ] security review;
- [ ] production build;
- [ ] deployment documentation;
- [ ] pending items explicitados.

## Entrega

Produzir:

- árvore do projeto;
- decisões;
- dependências;
- variáveis;
- Figma/Design System;
- desvios;
- pendências;
- QA report;
- instruções de execução/deploy.
