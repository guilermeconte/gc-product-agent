# Change Management

Toda alteração relevante deve ser tratada como Change Request.

Fluxo:
1. registrar alteração;
2. identificar origem;
3. calcular impacto;
4. localizar o primeiro nó afetado;
5. invalidar apenas dependências posteriores;
6. preservar checkpoints aprovados;
7. reaplicar alterações;
8. executar QA;
9. atualizar estado.

Nunca reconstruir o projeto inteiro quando somente uma parte foi afetada.
