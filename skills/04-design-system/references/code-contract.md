# Code Contract

O contrato de código relaciona:

- componente Figma → componente de implementação
- token → variável/CSS custom property
- página → rota
- motion → implementação
- estado → estado de UI
- responsive → media/container behavior
- accessibility → semântica e ARIA
- naming → nomes estáveis entre design e código

A implementação deve preservar o contrato salvo quando uma Change Request aprovada alterar o contrato.
