# Design System Baseline

O baseline é um ponto de partida, não uma imposição.

Inclui:
- brand
- foundations
- tokens
- typography
- layout
- spacing
- radius
- motion
- states
- primitives
- components
- patterns
- templates
- pages
- responsive
- accessibility

Primitivos base:
Container, Stack, Inline, Grid, Divider, Spacer, Icon, Image, Link, Text, Heading, Label, Eyebrow, Badge e Metadata.

Estados:
default, hover, active, focus-visible, disabled, loading, selected, error, success.

Figma deve representar uma estrutura implementável e nomeada, não apenas uma imagem.
