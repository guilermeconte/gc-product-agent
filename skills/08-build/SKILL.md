# Build Skill

## Objetivo

Implementar o produto usando a stack definida ou recomendada.

## Stack

O agente deve detectar/confirmar:

- framework;
- language;
- styling;
- state management;
- backend;
- database;
- CMS;
- auth;
- deployment.

Não presumir Next.js. O Design Contract é agnóstico.

## Regras

- preservar boundaries client/server;
- manter secrets no servidor;
- implementar tokens do Design System;
- respeitar naming contract;
- implementar motion contract;
- testes desde os fluxos críticos;
- registrar decisões arquiteturais.

## Saída

Código executável + `.project/build/implementation.md`
