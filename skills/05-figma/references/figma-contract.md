# Figma Contract

Figma is a structured representation of the product.

When a Figma MCP is connected:
1. Discover the available tools before acting.
2. Inspect the existing file and structure.
3. Never perform destructive bulk changes without a checkpoint.
4. Keep names aligned with the Design Contract.
5. Use variables, styles and components when supported.
6. Record unsupported operations.
7. Never invent MCP tool names.
